# 알프래드 저널 — 새 글 발행하는 법

이 폴더(`/posts/`)에 마크다운 파일(`.md`)만 추가하면 됩니다.  
별도 빌드·배포 명령 없이, 커밋만 하면 1~2분 안에 [alfred.pet/blog/](https://alfred.pet/blog/)에 자동 반영됩니다.

---

## 가장 빠른 방법 (폰에서, 1분 컷)

1. 폰에서 GitHub 앱(또는 브라우저로 `github.com/kwon8152/alfred-pet`) 열기
2. `posts/` 폴더로 이동 → **Add file → Create new file**
3. 파일 이름: `2026-05-20-제목.md` 형식 (날짜-슬러그)
4. `_TEMPLATE.md` 내용을 복사해 와서 채우기
5. **Commit changes** 누르기
6. 끝. 1~2분 뒤 사이트에 자동 발행됨

---

## 파일 이름 규칙

```
YYYY-MM-DD-slug.md
```

- 날짜는 발행일
- `slug`는 영문 소문자·숫자·하이픈만 (한글 안 됨 — URL 안 예뻐서)
- 예시:
  - ✅ `2026-05-20-eticat-customer-review.md`
  - ✅ `2026-06-01-la-office-update.md`
  - ❌ `에티캣 리뷰.md` (한글)
  - ❌ `review.md` (날짜 없음)

URL은 자동으로 이렇게 됩니다:  
`https://alfred.pet/blog/post.html?slug=2026-05-20-eticat-customer-review`

## 글 구조 (frontmatter)

모든 글은 맨 위에 이런 메타 정보로 시작합니다:

```markdown
---
title: 글 제목
date: 2026-05-20
excerpt: 목록에 노출되는 1~2줄 요약 (60~120자 권장)
cover: /images/eticat-hero.jpg
author: 알프래드
tags: [브랜드, 기술]
lang: ko
draft: false
---

여기서부터 본문...
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `title` | ✅ | 글 제목 |
| `date` | ✅ | `YYYY-MM-DD` (최신순 정렬 기준) |
| `excerpt` | 권장 | 비우면 본문 앞 120자를 자동으로 가져옴 |
| `cover` | 권장 | `/images/xxx.jpg` (없으면 기본 이미지 사용) |
| `author` | 선택 | 글쓴이 |
| `tags` | 선택 | `[태그1, 태그2]` 형식 |
| `lang` | 선택 | `ko` 또는 `en` (지금은 표시만, 필터는 안 함) |
| `draft` | 선택 | `true` 면 목록에서 숨김. 비공개 작업용 |

## 본문 — 마크다운 기본 문법

| 쓰고 싶은 것 | 마크다운 |
|---|---|
| 큰 소제목 | `## 제목` |
| 작은 소제목 | `### 제목` |
| **굵게** | `**굵게**` |
| *기울임* | `*기울임*` |
| 링크 | `[보일 글자](https://...)` |
| 이미지 | `![설명](/images/xxx.jpg)` |
| 목록 | `- 항목` 또는 `1. 항목` |
| 인용 | `> 인용문` |
| 코드 한 단어 | `` `코드` `` |
| 코드 블록 | ``` ```언어\n코드\n``` ``` |
| 가로선 | `---` |

## 자주 묻는 것

**Q. 미리보기 어떻게 봐요?**  
A. GitHub에서 파일 편집 화면 우측 상단의 **Preview** 탭을 누르면 마크다운 미리보기가 됩니다. 실제 사이트 디자인 적용된 모습은 발행 후 확인.

**Q. 글 수정하고 싶어요.**  
A. 같은 `.md` 파일을 열어서 **Edit (연필 아이콘)** → 수정 → Commit. 똑같이 1~2분이면 반영.

**Q. 글 삭제하고 싶어요.**  
A. 파일을 열어서 **휴지통 아이콘** → Commit. 또는 `draft: true` 로 바꿔두면 임시 숨김.

**Q. 이미지는 어디 올려요?**  
A. `/website/images/` 폴더에 올리고, 본문에서는 `/images/파일명.jpg` 로 참조하세요. 큰 이미지는 미리 1200px 정도로 줄이는 게 좋습니다 (모바일 속도).

**Q. `_TEMPLATE.md`는 왜 목록에 안 떠요?**  
A. 의도된 동작입니다. `_` 로 시작하는 파일은 자동 제외돼요. 안 지우셔도 됩니다.

**Q. 영어 글도 올릴 수 있나요?**  
A. 네. 그냥 영어로 쓰시고 `lang: en` 으로 표시만 해주세요. (지금은 영어/한국어 글이 같은 목록에 섞여서 표시됩니다 — 따로 분리하고 싶으면 알려주세요.)

## 트러블슈팅

- **글이 안 보여요** → 1~2분 기다려보세요. GitHub Pages 배포 + 브라우저 캐시 때문. 그래도 안 보이면 시크릿 모드로 확인.
- **이미지가 깨져요** → 경로 확인. `/images/...` 로 시작해야 함 (앞에 슬래시).
- **frontmatter 오류** → `---` 두 줄 사이에 정확히 있어야 함. 들여쓰기·콜론(`:`) 띄어쓰기 주의.
- **GitHub API rate limit** → 사이트 방문자가 시간당 60명 넘으면 목록 로딩이 잠깐 느려질 수 있음. 트래픽이 그 정도 되면 그때 보강합시다.
